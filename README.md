## 📲 Cách cài đặt (Esign)

1. Vào tab [**Releases**](../../releases) → Tải `Azzuill.ipa`
2. Gửi IPA sang iPhone (AirDrop / Files)
3. Mở **Esign** → Import file `Azzuill.ipa`
4. Bấm **Ký (Sign)** → Chọn certificate của bạn → **Ký ứng dụng**
5. Bấm **Cài đặt (Install)**
6. Vào `Cài đặt > Chung > VPN & Quản lý thiết bị` → Trust certificate
7. Mở **Azzuill** trên màn hình chính 🎮

